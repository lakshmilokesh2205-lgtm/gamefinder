# GameFinder

My app helps gamers on a budget decide which Steam games to purchase by comparing prices, ratings and playtime to find the best value.

> A course project for **MIST 4600: Computer Programming in Business** at the University of Georgia's Terry College of Business (Fall 2026).

## Problem
With so many choices at so many price points, it can be hard for budget gamers to know what Steam games are worth picking up. GameFinder lets them compare game ratings, prices and playtime to find the games that offer the most value.

## What it does
My app answers three questions: 
1. **Genre and budget:** Which highly rated games fit the genre and budget the gamer types in?
2. **Playtime value:** Which games offer the most hours of play for their price?
3. **Positive reviews:** Which games have the highest percentage of positive reviews within the gamer's budget?

## Data
The [Steam Games Dataset](https://www.kaggle.com/datasets/artermiloff/steam-games-dataset) on Kaggle, collected in March 2025. The dataset is shared under the MIT License by its creator, artermiloff. This repo uses `steam_games.csv`, a smaller file made for the course: the 1,000 games with the most reviews.
